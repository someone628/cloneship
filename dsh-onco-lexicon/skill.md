# 肿瘤学术语词典

本环境提供一部本地肿瘤学术语词典，**本地优先**：本地命中时无需联网即可查询；
本地未收录时，`onco_term` / `onco_abbr` 会自动联网查 NCI EVS（NCIt）与 NLM MeSH 兜底。

## 可用工具

- **onco_term**：按中文名、英文名、缩写或别名查询术语，返回标准名、缩写、别名、类别、释义与外部编码。
  本地未收录时自动联网兜底（输出分「本地未收录」与「【联网兜底】」两段）。
- **onco_abbr**：查询缩写的全部义项，用于消歧（如 OS、PD、MM 均有多个含义）。本地未收录时联网补查，
  但联网召回**不保证完整**，只能当补充线索。
- **onco_browse**：按类别浏览词条，或确认词典覆盖范围。只作用于本地词典，**不联网**。
- **onco_translate**：术语级中英对照。给一个术语的中英名，或从一段文本里找出所有命中的术语并逐条对照。
  只作用于本地词典，**不联网**。

## 使用原则

1. 涉及肿瘤学术语的定义、缩写、编码时，先查词典再回答。
2. 本地词典未收录时，工具会自动联网兜底。**必须区分**「本地词条」与「联网兜底」：
   联网内容未经本地人工整理，不得说成是本词典的词条。
3. 联网也查不到时如实说明未收录，不得编造释义、编码或出处。
4. **联网源（NCIt / MeSH）都是英文词表**：不能用中文检索，也不会返回中文名。
   中文查询本地未收录时，应说明这一点并请用户提供英文名或缩写，不得据中文名反推或编造英文名。
5. 缩写存在多义时先消歧；联网给出的缩写候选只是线索，不是穷尽列表。
6. **onco_translate 不是机器翻译**：它只做术语级对应，不做语序调整、语法重组与整句润色。
   不得把对照结果包装成流畅译文；未被词典收录的部分必须原样保留，不得自行补译。
7. 词典中带中文名的条目仅 106 条（人工整理），英译中时大量术语没有中文名——
   此时如实说明「词典未收录中文名」，不要替它编一个。
8. 本词典仅供科研与文献理解，不提供诊疗建议。
