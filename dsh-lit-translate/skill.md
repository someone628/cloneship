# 文献翻译

本环境装有文献翻译插件（工具名 `lit_translate`），用 DSH 当前的默认模型做学术英译中。
它由文献阅读插件里的翻译链路单独抠出，只负责翻译这一件事。

## 可用工具

- **lit_translate**：把英文文献内容译成流畅、准确的学术中文。
  - `text`：要翻译的英文内容（必填）。
  - `context`：上一段的原文（可再附上它的中文译文）。只用于统一术语、缩写与指代，
    不会被翻译、也不会出现在译文里。
  - `annotate`：术语首次出现是否写成「中文（English）」形式，默认 `true`；要纯中文时传 `false`。
  - `mesh`：本次是否启用 MeSH 术语约束，默认 `true`（取插件配置）。

## 使用原则

1. 长文献按段落分次调用；每段把上一段放进 `context`，可显著减少同一术语前后译法不一致。
2. 与 `onco_translate` 的分工：`onco_translate` 只做**术语级对照**（不做语序调整，结果不是译文）；
   需要整段可读的中文时用 `lit_translate`。
3. 它是翻译工具，不是文献解读工具：总结、评价、提取数据、回答研究问题都不要用它。
4. 转述结果时要说明这是机器译文；数字、单位、P 值、置信区间、样本量、基因位点必须与原文一致，
   不得据译文推断原文没有的结论。
5. 侧边栏「文献翻译」面板适合人手翻整篇：粘贴或导入 txt / md → 切段 → 逐段翻译 → 导出 Markdown。
   工作稿保存在 `$DSH_HOME/lit-translate/doc.json`，面板上可开关「MeSH 术语约束」。

## 关于 MeSH 术语约束（别把它说成术语词典）

- MeSH（医学主题词表）由美国国家医学图书馆（NLM）生产，**只有英文，没有中文名**。
  这一层只做三件事：把原文写法收敛到 MeSH 规范名、用 ScopeNote 给同形词消歧、给出 MeSH 编号便于回查。
- 因此**不要**把 MeSH 编号说成"官方中文名的依据"，也不要声称某个中文译名是 MeSH 官方译名；
  中文译名一律由模型按医学翻译规范给出。
- MeSH 覆盖有限：`PD-L1`、`NSCLC`、`hazard ratio` 这类常见写法在 MeSH 2026 里**没有**对应条目
  （只有 `PD-L1 Costimulatory Protein`、`PD-1 Protein` 这类全称），所以命中为空是正常情况，不是故障。
- 索引缺失或损坏时翻译照常可用，工具输出里会写明"未生效"。
