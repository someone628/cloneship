# CT 报告实体归一化

本环境提供 `ct_norm` / `ct_lexicon` 两个工具，把放射科 CT 报告里的**中文自由描述**
按本地人工整理的词表映射到 **MeSH 2026 标准概念**，解决「临床医生写法五花八门、
同一个发现几十种写法」的问题。

**全程离线**：不联网、不调用模型。归一化只做两件事——词表命中，以及「部位 + 形态学词」
的固定规则组合。因此结果可复现、可审计。

## 可用工具

- **ct_norm**：输入 CT 报告原文，输出「实体 → MeSH 概念」对照表。分四栏：
  归一化结果、未归一化、概念汇总、仅识别到部位。`format: "json"` 可拿结构化结果。
- **ct_lexicon**：查词表本身——某个写法对应哪个 MeSH 概念、收录了哪些写法、
  某个 MeSH 编号有哪些中文写法、以及词表**没**收录什么。

## 使用原则（重要）

1. **必须一起转述「未归一化」那一栏。** 只讲命中、不讲漏收，会让听者以为报告里
   每个描述都已被规范化——这比没有结果更危险。
2. **未归一化不是工具坏了。** MeSH 主题词表以**疾病实体**为粒度，磨玻璃影、毛刺、
   分叶、低密度灶、壁增厚这类**影像描述性征象在 MeSH 里没有对应概念**。
   不得为它们编一个 MeSH 编号，也不要用「大概是某某概念」搪塞。
3. **标了「规则组合」的是外推。** 如「肝转移瘤」→ Liver Neoplasms ＋ Neoplasm Metastasis，
   来自「部位 + 形态学词」规则，**不等于病理诊断**，转述时必须带上这一点。
4. **标了「歧义」的不要替用户选。** 如「肺结节」未写单发/多发时，MeSH 有
   Solitary Pulmonary Nodules 与 Multiple Pulmonary Nodules 两个不同描述符，
   工具会同时给出候选并说明待确认的问题。
5. **标了「否定」的不是阳性发现。** 「未见胸腔积液」表示报告否定了该发现；
   「不除外转移」是**有可能**，与否定相反，不要把两者混为一谈。
6. **不产出中文译名。** MeSH 只有英文；条目里的中文是**词表收录的中文写法**，
   不是 MeSH 官方中文名。不要说「MeSH 中文名是……」。
7. **覆盖范围就是词表本身。** 用户问「某写法为什么没识别出来」时，用 ct_lexicon 确认收录情况，
   如实说明未收录即可。
8. 涉及诊断结论、分期、治疗方案的问题，本工具只做名词层面的归一化，
   须提示以临床指南与医师意见为准。

## 已知边界

- 词表规模见 `ct_lexicon` 输出的元信息（当前约 327 条写法条目 / 2190 个表面写法 / 370 个 MeSH 概念）。
- 词表**覆盖有限**，且刻意不收「病灶」「病变」「占位」这类无法定性为 MeSH 概念的泛化写法
  （「占位/肿块」只有绑定到部位时才按规则外推，并明确标注）。
- 侧别、程度、数量、尺寸等属性取自实体所在的**小句**，不保证每个词都直接修饰该实体，
  输出里已注明，请以原文复核。
