# dsh-ct-norm 允许使用的 MeSH 2026 规范名（白名单）
#
# 每行一个 MeSH **描述符规范名**（DescriptorRecord 的 Name）。
# 这一份白名单是在 MeSH 2026 索引（355,232 条记录 / 840,392 条术语）上逐条实测命中的结果，
# 不是凭记忆写的。源文件里 `mesh` 字段取这里的名字即可。
#
# 说明：
#   * 名字大小写、逗号必须与这里完全一致（如 `Colon, Sigmoid`，不是 `Sigmoid Colon`）。
#     实际上构建脚本按 MeSH 术语索引反解，MeSH 的入口词（entry term）也能命中，
#     但白名单以规范名为准，避免你写了一个我没想到的入口词却在别处对不上。
#   * 构建脚本最终仍会拿源文件去**真实索引**里反解一次；这里只是写作阶段的对照表。
#   * 需要用到白名单之外的概念时，先加进本文件并跑 `node build-ct-lexicon.mjs --check` 验证。
#   * `[解剖]` 段里带 `→ 肿瘤:` 的，就是该部位可用于 `neoplasm` 字段的组合目标。
